How an HTML report gets published

CoCo writes a self-contained HTML file. Before anyone sees it, Snowflake sanitizes it and renders it inside a locked-down sandbox. Publishing turns the file into an artifact with a stable link that stays the same as you ship new versions.

Publishing and updating

The conversation between you, CoCo, and Snowflake when you publish and then republish.

  1. Sanitize strips anything outside the allowed surface (inline handlers, remote resources).
  2. Renderer loads only the vendored /libs/ libraries the page references.
  3. Sandbox runs the page with a strict Content-Security-Policy and no network access.
  4. Report is what the reader sees, behind a link that doesn't change between versions.
