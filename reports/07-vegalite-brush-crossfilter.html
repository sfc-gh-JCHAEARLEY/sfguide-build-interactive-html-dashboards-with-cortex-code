Query Log: Brush to Cross-Filter

HTML_REPORTS_QS.DEMO.QUERY_LOG · 2,000 queries · Vega-Lite linked selection

Brush the scatter to filter query types

Drag a rectangle on the scatter to filter the bar chart to those queries; double-click the scatter to clear.

SELECT warehouse_size, query_type, rows_scanned, duration_ms
FROM HTML_REPORTS_QS.DEMO.QUERY_LOG
ORDER BY warehouse_size, query_type, rows_scanned, duration_ms

What this shows: Top: one point per query, rows scanned (x) against duration in ms (y), both log scales, colored by warehouse size. Bottom: the number of queries of each query_type.

Source: HTML_REPORTS_QS.DEMO.QUERY_LOG, all 2,000 rows, inlined from the query in the SQL view.

How the cross-filter works: The scatter defines a Vega-Lite interval selection (params: [{name: 'brush', select: {type: 'interval'}}]). The bar chart applies transform: [{filter: {param: 'brush'}}], so its counts are recomputed from only the brushed rows on every drag. Points outside the brush turn gray. Double-click clears the brush, and an empty brush lets every row through.

Caveat: 5 queries (all on Large) have duration_ms = 0 and can't sit on a log axis, so the scatter plots 1,995 points. With no brush the bars count all 2,000. A brush can never include those 5. QUERY_LOG is synthetic sample data.
