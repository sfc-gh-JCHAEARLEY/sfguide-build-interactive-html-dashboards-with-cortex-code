    What this shows: Every object in the dependency table as a node, and every row as a directed edge (arrow points from SOURCE_NAME to TARGET_NAME).

    Source: HTML_REPORTS_QS.DEMO.OBJECT_DEPENDENCIES, all 11 rows, no filters.

    How it was derived: Nodes are the distinct names on either side of an edge, colored by their type. Node size grows with the number of direct connections. A gentle horizontal pull orders the layout Source table → Report → Role → User so the flow reads left to right.

    Relationships: Source table → Report means the table feeds the report; Report → Role/User means the report is shared with that grantee; Role → User means the role is granted to the user. These labels are inferred from the node types.

    Caveat: The layout is a physics simulation, so positions differ from one load (or shake) to the next. Only position carries no meaning; colors and arrows do.
