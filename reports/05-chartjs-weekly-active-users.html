What this shows: Active users per week, for the most recent N weeks chosen with the slider (4 to 52).

Source: HTML_REPORTS_QS.DEMO.WEEKLY_ACTIVE_USERS, all 52 rows (weeks starting Monday, Nov 3, 2025 to Oct 26, 2026). Values are inlined from the query in the SQL view; nothing is fetched when you view the page.

How it was derived: No aggregation. Each point is one row. The window keeps the latest N weeks. The summary line compares the first and last week in the window.

Caveat: Randomize swaps in synthetic demo values. It uses a seeded generator (mulberry32) with the same formula as the table's setup script, 1200 + 35×week + uniform(−120, 120), so the values only change when you click. While randomized, a "Randomized" badge appears and the Preview shows real and plotted values side by side. Show real data puts the Snowflake values back. The table itself is synthetic sample data.
